Privacy Policy

Poddars Publisher · Last updated 30 October 2026

Poddars Publisher is a private tool that uploads Poddars Finance's own films to Poddars Finance's own YouTube channels. This policy explains what it does with Google account data.

What it accesses

When a channel owner signs in with Google and allows access, the tool can:

  • read the channel's ID and name, to record which channel was linked;
  • upload videos to that channel, set their thumbnails and captions, and set when they become public.

It does not read email, contacts, files, comments, viewing history or any other account data.

Where data is kept

The access token Google returns is stored only on the owner's own computer, in the tool's folder. Nothing is sent to any server other than Google's own YouTube API. The tool never sees or stores a password.

Sharing

No data is sold, shared with third parties, or used for advertising.

YouTube API Services

This tool uses YouTube API Services. By using it you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Removing access

Access can be withdrawn at any time at myaccount.google.com/permissions. Deleting the tool's folder removes every stored token.
